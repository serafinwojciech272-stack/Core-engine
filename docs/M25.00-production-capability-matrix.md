## Evidence rules

- **VERIFIED** means direct evidence exists for the specific behavior, not merely code or a declared status.
- **PARTIAL** means some components or paths are evidenced but the full end-to-end capability is not.
- **NOT WORKING** means a concrete failure was observed.
- **NOT VERIFIED** means the audit has not yet produced sufficient evidence. It is not equivalent to failure.
- A successful build/deploy is not proof that a user-facing capability works end-to-end.

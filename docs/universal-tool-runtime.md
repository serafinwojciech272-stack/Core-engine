# M201-M225 Universal Tool Runtime
The tool layer adds governed adapters for MCP, browser research, computer use, code execution, sandbox, files, databases and APIs.

Every tool has a contract, permission scope, risk/cost model, provider arbitration, fallback path, evidence, verification, retry/circuit controls and certification.

Important: this package defines the governed runtime boundary. It does not silently execute external side effects. Real providers must enter through existing approval, credential, policy and execution gates.

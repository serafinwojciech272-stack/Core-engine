# Universal Skill Intelligence M176-M200

Core Engine extends its governed Universal Agent with a first-class Skill Intelligence Layer.

Pipeline:
OBJECTIVE → WORLD MODEL → SKILL DISCOVERY → SEMANTIC MATCHING → COMPOSITION → DEPENDENCIES → PRECONDITIONS → POLICY/RISK/BUDGET → HUMAN APPROVAL → EXECUTION → VERIFICATION → EVIDENCE → OUTCOME → PERFORMANCE MEMORY → LEARNING → VERSIONING → REGRESSION → CERTIFICATION → REGISTRY → CONTROL PLANE

A skill is a governed execution unit, not a plain function. Its contract includes inputs, outputs, preconditions, postconditions, actions, providers, permissions, dependencies, risk, cost, verification, fallbacks, performance and lifecycle status.

Safety invariant:
NO APPROVAL → NO SKILL EXECUTION.

The control plane blocks execution when approval is absent, budget is exceeded, risk is excessive, preconditions are missing or skill conflicts exist.

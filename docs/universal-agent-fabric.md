# M136-M150 Universal Agent Fabric

The Universal Agent Operating System is extended with a governed infrastructure fabric for durable lineage, idempotency, routing, context, budgets, leases, evidence, learning, recovery classification, provider health, handoff, scope, memory reconciliation and certification.

Stages 136-150 form the infrastructure layer beneath the closed-loop runtime.

Core safety rule: the fabric never grants execution permission. It only supplies deterministic controls and evidence to the existing approval/execution boundary.

M150 is a readiness gate, not an autonomous bypass. A run is ready only when certification, provider availability, budget, idempotency and existing approval controls are satisfied.

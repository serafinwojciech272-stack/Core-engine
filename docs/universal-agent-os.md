# Universal Agent OS M301-M350
This layer integrates objective, world model, skills, tools, agents, execution mesh, governance, approval, evidence, verification, outcomes, learning, memory, recovery and interoperability into one governed lifecycle.
Core invariant: NO APPROVAL → NO EXECUTION. Recovery invalidates prior execution permission and returns the run to approval.
M301-M350 is the OS integration/certification layer, not a bypass around existing gates.
